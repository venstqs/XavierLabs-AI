System Architecture

The Continuous Agentic Loop

Operating as a decentralized swarm of specialized AI personas. Each agent owns a specific phase of the computational scientific method.

🔭

The Ideator

Discovery & Hypothesis

Queries official ArXiv and Semantic Scholar APIs without paid keys. Synthesizes literature and codebases into mathematically sound JSON hypotheses.

  • Zero-key ArXiv & Semantic Scholar queries
  • Workspace codebase & dataset ingestion
  • Strict JSON hypothesis schema
⚖️

The Reviewer

Critique & Logic

Simulates a rigorous peer-review committee. Evaluates hypotheses for novelty and rigor (1-10) and audits candidate scripts for safety and reproducibility.

  • Novelty, rigor & feasibility scoring
  • Rejects trivial ideas with feedback
  • Pre-flight script risk auditing
⚡

The Coder

Execution & Auto-Debugging

Translates hypotheses into runnable Python experiments. If a simulation crashes, captures the stderr traceback and autonomously rewrites the fix.

  • Self-contained experiment.py scripts
  • Reproducibility seed enforcement
  • Autonomous stderr traceback repair
📄

The Synthesizer

Manuscript & Visuals

Generates publication-grade Matplotlib/Seaborn visualization scripts and compiles academic LaTeX and PDF manuscripts ready for submission.

  • Automated plot.py figures
  • Publication-grade LaTeX manuscript
  • Headless PDF paper compilation
Self-Healing Runtime

Zero-Crash Autonomous Execution

Computational science scripts often fail due to matrix dimension mismatches, missing packages, or type issues. XavierLabs AI never halts on error—it catches the exact traceback and heals the script autonomously.

  • ✓
    Dual Sandbox Engine:
    Runs in Docker containers when available, with automatic isolated local subprocess fallback.
  • ✓
    Stderr Feedback Loop:
    Crashes are parsed, analyzed for root causes, and rewritten by The Coder up to 3 retries.
  • ✓
    Strict Compute Timeouts:
    Enforces execution time limits to protect local hardware from infinite loops or runaway memory.

Quickstart

Get Started in 60 Seconds

Deploy XavierLabs AI on your local terminal and start launching parallel computational experiments.

1

Clone or Install the CLI

Install via git or editable pip mode into your virtual environment:

git clone https://github.com/venstqs/XavierLabs-AI.git && cd XavierLabs-AI && pip install -e .
2

Configure Your LLM Provider

Create your .env file with Gemini, OpenAI, or connect local Ollama models:

echo "GEMINI_API_KEY=your_key_here" > .env
3

Launch Autonomous Research

Provide any scientific topic or algorithmic inquiry to trigger the swarm:

xavier research "Analyze AdamW vs Lion optimizer on non-convex loss functions"
4

Open the Compiled Paper

View all generated paper formats and open the PDF automatically in your browser:

xavier paper experiments/your_experiment_folder --open
