Agents

Four agents work in sequence, and each one checks the previous step's output.

ideator

Searches ArXiv and Semantic Scholar and drafts a testable hypothesis

reviewer

Scores novelty, rigor and feasibility, and sends weak ideas back for revision

coder

Writes a seeded, self-contained experiment that saves its results to metrics.json

sandbox

Runs the code in an offline Docker container or a locked-down subprocess

auto-debug

Reads the traceback from a failed run and patches the script

synthesizer

Plots the metrics and writes the report, LaTeX source, HTML and PDF

Commands

Run xavier for the interactive console, or use a command directly from your shell.

xavier research "<topic>"

Run the full loop, from literature to compiled paper

xavier paper <folder>

Inspect a run's outputs and open the paper

xavier history

List past experiments and their status

xavier auth

Add a provider key and test it live

xavier config

Show the active model, keys and sandbox

xavier run <script>

Run any script in the sandbox

Models

Use any provider through LiteLLM, or keep everything on your machine.

Cloud

Groq, DeepSeek, OpenRouter, OpenAI, Anthropic and Gemini

Local

Ollama, fully offline with no API keys

Custom

Any OpenAI-compatible endpoint, such as LM Studio or vLLM
