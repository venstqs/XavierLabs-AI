From research question to paper. Autonomously.

XavierLabs AI is a terminal-native swarm of four agents. It reads the literature, proposes a testable hypothesis, writes and runs a real experiment in a sandbox, fixes its own crashes, and compiles the results into a paper you can open.

Get started Watch a run
$pip install git+https://github.com/venstqs/XavierLabs-AI.git
Python 3.10+ · macOS, Linux, Windows · Docker optional

        02Pipeline
        
Four agents. One loop.

        
Each agent has one job, and the output of every stage is checked before the next one starts.


        

          

            
01

            
Ideator

            
Searches ArXiv and Semantic Scholar, then writes a falsifiable hypothesis as strict JSON.

            literature
          

          

            
02

            
Reviewer

            
Scores novelty, rigor and feasibility. Rejected ideas go back for revision, or the run stops.

            peer review
          

          

            
03

            
Coder

            
Writes a seeded, self-contained experiment.py that must save its results to metrics.json.

            experiment
          

          

            
04

            
Sandbox

            
Runs the script in an offline Docker container or a locked-down subprocess, and records every attempt.

            execution
          

          

            
05

            
Synthesizer

            
Plots the metrics and writes the report, LaTeX source, HTML paper and PDF.

            paper
          

        

        

          
          If a run crashes or produces no metrics, the Coder reads the traceback and patches the script, up to your retry limit.
        

      

    


    
    

      

        03Features
        
Claims backed by code that ran.

        
Every number in the paper comes from a script you can open, rerun and audit.


        

          

            

            
Isolated execution

            
Docker runs come with numpy, scipy and matplotlib preinstalled, no network, and memory, CPU and process limits. The local fallback hides your API keys from generated code and keeps its temp files inside the workspace.

            
network: nonemem 2gkeys scrubbed

          

          

            

            
Self-repairing code

            
Crashes, timeouts and missing metrics go back to the Coder along with the traceback.

          

          

            

            
Papers in four formats

            
paper.pdf, paper.tex, paper.html with MathJax, and report.md, plus a 300-DPI figure.

          

          

            

            
Any model

            
Use Groq, DeepSeek, OpenRouter, OpenAI, Anthropic or Gemini, or run fully offline with Ollama.

            
via LiteLLM

          

          

            

            
Full audit trail

            
Every hypothesis, review score, script version and run is saved to SQLite. Browse it with xavier history.

          

          

            

            
Terminal-native

            
An interactive console for brainstorming ideas, plus one-shot commands for scripting.

          

        

      

    


    
    

      

        04CLI
        
Five commands to learn.


        

          
xavierOpen the interactive console to brainstorm, then launch runs.

          
xavier research "<topic>"Run the full loop end to end. Add --force to run even if the Reviewer rejects the hypothesis.

          
xavier paper <folder> --openInspect and open a run's PDF, HTML, LaTeX and Markdown.

          
xavier historyBrowse past experiments and their status.

          
xavier configShow the active model, detected keys and sandbox engine.

        

      

    


    
    

      

        05Quickstart
        
Running in under a minute.


        

          

            

              
01
Install

              
Python 3.10 or newer. Docker is optional but recommended.

            

            
pip install git+https://github.com/venstqs/XavierLabs-AI.git

          

          

            

              
02
Connect a model

              
Paste a key and verify it with a live test, or choose local Ollama.

            

            
xavier auth

          

          

            

              
03
Run research

              
Artifacts are saved to experiments/<topic>_<time>/.

            

            
xavier research "AdamW vs Lion on non-convex loss surfaces"
