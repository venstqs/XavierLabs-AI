01 // Architecture

The 4-Agent Orchestration Swarm

Four specialized agents execute the scientific method in a continuous stateful loop triggered via a single CLI invocation.

[01]

The Ideator

Discovery & Hypothesis

Ingests codebases and queries academic databases (ArXiv, Semantic Scholar) via zero-key open APIs. Formulates mathematically sound hypotheses formatted as JSON configurations.

  • Open-access ArXiv queries
  • Semantic Scholar citation graphing
  • Strict JSON schema generation
[02]

The Reviewer

Adversarial Peer Critique

Simulates a rigorous peer-review process. Scores hypotheses for novelty and theoretical rigor (1-10) and audits the Coder’s scripts for architectural flaws prior to execution.

  • Novelty & rigor validation
  • Rejects hand-waving claims
  • Pre-flight safety & leak auditing
[03]

The Coder

Execution & Auto-Debugging

Translates approved hypotheses into executable Python scripts (experiment.py). If a run crashes, ingests the stderr traceback and autonomously rewrites and re-executes the code.

  • Deterministic random seeds
  • Self-contained simulation code
  • Automated traceback repair loop
[04]

The Synthesizer

Artifact Compilation

Extracts metrics, generates data visualization scripts (plot.py) using Matplotlib, and compiles complete publication-grade LaTeX, PDF, and Markdown manuscripts.

  • Automated publication charts
  • Standard LaTeX manuscript
  • Direct PDF paper compilation
02 // Containment & Auto-Debug

Self-Healing Execution Runtime

Generated experiments execute within isolated boundaries. If runtime exceptions occur, the CLI feeds the traceback directly back to the Coder agent to resolve the issue without human intervention.

Traditional agent harnesses stop immediately when code crashes. XavierLabs AI isolates runtime processes, captures stderr telemetry, diagnoses algorithmic failures, and applies pinpoint patches.

  • [+]
    Dual Sandbox Architecture Spins up Docker containers when available, with an automatic isolated local subprocess fallback.
  • [+]
    Traceback Diagnosis Loop Captures stack traces from stderr, extracts failure lines, and rewrites corrected scripts up to 3 iterations.
  • [+]
    Strict Resource Guardrails Enforces execution timeouts and memory quotas to ensure host machines remain responsive.

04 // Deployment

Quickstart Setup

Install the CLI, configure compute routing, and initiate your first autonomous computational experiment.

01
Install Repository
Clone the repository and install dependencies in editable mode:
git clone https://github.com/venstqs/XavierLabs-AI.git && cd XavierLabs-AI && pip install -e .
02
Configure Provider Keys
Set your LLM provider key (Gemini, OpenAI) or connect local Ollama models:
echo "GEMINI_API_KEY=your_key_here" > .env
03
Initiate Research Loop
Pass a scientific topic to trigger the autonomous multi-agent swarm:
xavier research "Analyze AdamW vs Lion optimizer on non-convex loss functions"
04
Inspect Research Paper
View generated paper formats and open the PDF automatically:
xavier paper experiments/your_experiment_folder --open
