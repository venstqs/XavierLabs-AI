xavierlabs

Terminal-native computational scientific research engine.

From literature review to compiled LaTeX papers, in one command.

$pip install git+https://github.com/venstqs/XavierLabs-AI.git
Python 3.10+ · macOS, Linux, Windows · Open Source (MIT)
01 // DISCOVERY

Literature & Hypothesis

Queries ArXiv and Semantic Scholar without paid API keys. Identifies open gaps in computational research and formulates mathematically testable hypotheses.

02 // PEER REVIEW

Adversarial Audit

Simulates an expert peer reviewer to critique mathematical soundness and feasibility before code runs. Scores proposals from 1 to 10 and rejects ill-posed formulations.

03 // CONTAINMENT

Sandboxed Auto-Debugger

Runs generated simulations in Docker or isolated local sandboxes. When code crashes, it intercepts the stderr traceback and autonomously rewrites and repairs the script.

04 // SIMULATION

Empirical Verification

Writes self-contained scientific Python simulations (NumPy, SciPy). Fixes deterministic seeds and outputs hard computed results to metrics.json.

05 // SYNTHESIS

Publication-Ready Papers

Renders 300-DPI Seaborn figures and compiles complete academic manuscripts in LaTeX (paper.tex), camera-ready PDFs (paper.pdf), and Markdown.

06 // MULTI-MODEL

Universal Model Support

Connect Groq for sub-second execution, DeepSeek for mathematical reasoning, OpenRouter for 100+ models, or run 100% privately and offline via local Ollama.

// CLI COMMANDS & WORKFLOW
xavier # Start interactive chatbot console (Antigravity CLI style)
xavier research "Your research inquiry" # Run autonomous end-to-end loop
xavier paper experiments/your_folder --open # View and open compiled PDF / LaTeX paper
xavier history # Browse audit trail of past computational experiments
xavier config # Inspect active LLM model, detected API keys, and sandbox
// QUICKSTART WORKFLOW
# 1. Install the CLI
pip install git+https://github.com/venstqs/XavierLabs-AI.git

# 2. Add your LLM provider (Groq, DeepSeek, OpenRouter, or Ollama)
echo "GROQ_API_KEY=gsk_..." > .env
# or: echo "DEEPSEEK_API_KEY=sk-..." > .env
# or: echo "OPENROUTER_API_KEY=sk-or-..." > .env

# 3. Launch interactive chatbot mode
xavier

# 4. Or run direct one-liner autonomous research
xavier research "Analyze AdamW vs Lion optimizer on non-convex loss functions"

# 5. View and open the compiled research paper
xavier paper experiments/your_experiment_folder --open
