Open source research agent

Research on autopilot.

It reads the literature

Give XavierLabs a question. A team of four AI agents finds the papers, tests a hypothesis with real code in a sandbox, fixes its own crashes, and hands you a finished paper.

How it works

      
One command runs the whole loop. Every number in the paper comes from code that actually ran.

      
    
        
  1. 1
    Find
    Searches ArXiv and Semantic Scholar, then writes a hypothesis you can test.
    2. 
        
  2. 2
    Review
    A reviewer agent scores the idea and sends weak ones back before any code runs.
    3. 
        
  3. 3
    Experiment
    Writes Python and runs it in a sandbox. If it crashes, it reads the error and fixes it.
    4. 
        
  4. 4
    Write
    Plots the results and writes the paper as PDF, LaTeX, HTML and Markdown.
    5. 
      

    


    

      
Install

      
Python 3.10 or newer. Works with any model provider, or offline with Ollama.


      

        

          
          
          
        

        

          pip install git+https://github.com/venstqs/XavierLabs-AI.git
          
        

      


      

        
xavierOpen the interactive console

        
xavier research "your question"Run the full loop and get a paper

        
xavier paper <folder> --openOpen a finished paper

        
xavier historySee past runs
