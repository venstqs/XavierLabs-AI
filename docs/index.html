xavierlabs

An autonomous, terminal-native research engine executing the computational scientific method end-to-end. Runs literature ingestion, mathematical hypothesis generation, sandboxed execution with automated traceback debugging, and publication-ready manuscript synthesis.

01 // Agentic Swarm Pipeline 4 personas
The Ideator
discovery
Queries academic repositories (ArXiv, Semantic Scholar) without paid API keys. Reads codebase context and formulates mathematically sound hypotheses as structured JSON configurations.
The Reviewer
adversarial critique
Simulates a rigorous peer-review committee. Evaluates hypotheses for novelty, mathematical consistency, and computational feasibility (1-10), auditing code for safety prior to execution.
The Coder
execution & repair
Translates approved hypotheses into reproducible Python scripts (experiment.py). If code crashes, ingests stderr tracebacks, locates bugs, and patches code autonomously.
The Synthesizer
artifact compilation
Extracts telemetry, writes visualization scripts (plot.py), and compiles academic LaTeX manuscripts (paper.tex), publication PDFs (paper.pdf), and structured Markdown reports.
02 // Autonomous Traceback Healing closed-loop sandbox

Unlike standard agent frameworks that abort on unhandled exceptions, XavierLabs runs in an isolated subprocess/Docker boundary. It traps runtime crashes, diagnoses the failure point, and self-heals:

// Attempt 1: Fatal Runtime Exception in isolated sandbox Traceback (most recent call last): File "experiment.py", line 42, in <module> loss = criterion(pred, target) ValueError: Expected target shape (100,) but got (100, 1) // Coder diagnoses exception & applies patch > Patch: target.squeeze(-1) applied at line 42 // Attempt 2: Execution re-run ✔ Return Code: 0 (Execution succeeded in 0.62s) ✔ Numerical metrics written to metrics.json

04 // Command Reference cli interface
xavier research "<topic>" Launch end-to-end autonomous research loop (discovery, critique, code, execution, manuscript).
xavier research --codebase <dir> Ingest existing code, papers, or dataset files alongside online literature.
xavier paper <dir> --open Compile and open the research paper PDF in your default browser or viewer.
xavier history Inspect experiment runs, hypothesis records, and artifact counts in the SQLite database.
xavier run <script.py> Execute any Python experiment script standalone inside the isolated sandbox.
xavier config Display model routing (Ollama / Gemini / OpenAI), sandbox type, and environment keys.
