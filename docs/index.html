xavierlabs

Terminal-native computational scientific research engine.

From literature review to compiled LaTeX papers, in one command.

$pip install git+https://github.com/venstqs/XavierLabs-AI.git
Python 3.10+ · macOS, Linux, Windows · Open Source (MIT)

Literature & Hypothesis

Queries ArXiv and Semantic Scholar without paid API keys. Cross-references papers with your local workspace and formulates mathematically testable hypotheses.

Sandboxed Auto-Debugger

Runs generated simulations in Docker or isolated local sandboxes. When code crashes, it traps the exact traceback and autonomously repairs the script.

Publication-Ready Papers

Renders high-DPI scientific charts and compiles complete academic manuscripts in LaTeX (.tex), publication PDFs (.pdf), and interactive HTML.

// QUICKSTART WORKFLOW
# 1. Install the CLI
pip install git+https://github.com/venstqs/XavierLabs-AI.git

# 2. Add your LLM provider (OpenRouter, DeepSeek, Ollama, Gemini, etc.)
echo "OPENROUTER_API_KEY=sk-or-..." > .env
# or: echo "DEEPSEEK_API_KEY=sk-..." > .env
# or 100% offline: ollama run deepseek-r1 (no key required!)

# 3. Run autonomous research on any topic
xavier research "Analyze AdamW vs Lion optimizer on non-convex loss functions"

# 4. View and open the compiled research paper
xavier paper experiments/your_experiment_folder --open
