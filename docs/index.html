System Architecture

The Continuous Agentic Loop

A stateful multi-agent orchestration pipeline where each persona owns a rigorous phase of the scientific method.

The Ideator

Discovery & Hypothesis

Queries academic databases (ArXiv, Semantic Scholar) via zero-key open APIs. Ingests codebases and generates novel hypotheses formatted as strict JSON configurations.

  • ArXiv & Semantic Scholar queries
  • Codebase & dataset ingestion
  • Structured JSON hypothesis schema

The Reviewer

Critique & Logic

Simulates a rigorous peer-review process. Evaluates hypotheses for novelty and theoretical rigor (1-10) and audits scripts for architectural flaws before execution.

  • Novelty, rigor & feasibility scoring
  • Adversarial hypothesis rejection
  • Pre-flight code safety auditing

The Coder

Execution & Auto-Debugging

Translates hypotheses into executable machine learning and simulation scripts. If a run crashes, ingests stderr tracebacks and autonomously rewrites the code.

  • Deterministic seed enforcement
  • Self-contained experiment.py
  • Traceback auto-debugging feedback loop

The Synthesizer

Manuscript & Visuals

Generates data visualization scripts (plot.py) using Matplotlib and compiles final academic methodology reports in LaTeX, PDF, and Markdown.

  • Automated Matplotlib figures
  • Standard LaTeX source code
  • Direct academic PDF compilation
Self-Healing Containment

Zero-Crash Autonomous Execution

Autonomous science code often crashes on edge-cases or dimension mismatches. XavierLabs AI isolates runtime processes, intercepts stderr tracebacks, and repairs code in a closed loop.

  • ✓
    Dual Sandbox Engine
    Executes within isolated Docker containers when available, with an automatic secure local subprocess fallback.
  • ✓
    Traceback Feedback Loop
    Crashes are parsed, analyzed for root causes, and rewritten by The Coder up to 3 automated retries.
  • ✓
    Strict Guardrail Timeouts
    Enforces strict compute limits to prevent runaway loops or memory leaks on local hardware.

Quickstart

Get Started in 60 Seconds

Install the CLI on your machine and launch your first computational scientific experiment.

01

Clone or Install the CLI

Install via git or editable pip mode into your virtual environment:

git clone https://github.com/venstqs/XavierLabs-AI.git && cd XavierLabs-AI && pip install -e .
02

Configure Provider Keys

Set your cloud provider key (Gemini, OpenAI) or connect local Ollama models:

echo "GEMINI_API_KEY=your_key_here" > .env
03

Initiate Research Loop

Provide any scientific topic or algorithmic comparison to trigger the swarm:

xavier research "Analyze AdamW vs Lion optimizer on non-convex loss functions"
04

Inspect Research Paper

View all generated paper formats and open the PDF automatically in your browser:

xavier paper experiments/your_experiment_folder --open
